# 課題B-01 ブログシステムの高度なデータ抽出API

## 概要

`ActiveRecord実践ミニ課題：ブログシステムの高度なデータ抽出API` という課題で作成したRailsアプリケーション。

## 課題内容

### 📋 ActiveRecord実践ミニ課題：ブログシステムの高度なデータ抽出API

#### **【1. データモデルとアソシエーションの定義】**

以下の4つのモデルを作成し、適切なアソシエーション（関連付け）を設定してください。

1. **User（ユーザー）**
    - 属性：`name:string`
    - 関連付け：複数の記事（Articles）を持つ、複数のコメント（Comments）を持つ
2. **Article（記事）**
    - 属性：`title:string`, `body:text`, `user_id:integer`
    - 関連付け：1つのユーザー（User）に属する、複数のコメント（Comments）を持つ、複数のタグ（Tags）を持つ（多対多）
3. **Comment（コメント）**
    - 属性：`content:text`, `user_id:integer`, `article_id:integer`
    - 関連付け：1つのユーザー（User）に属する、1つの記事（Article）に属する
4. **Tag（タグ）**
    - 属性：`name:string`
    - 関連付け：複数の記事（Articles）を持つ（多対多、中間テーブルを用意すること）

#### 【2. 実装要件（クエリ作成）】

以下の3つのデータ抽出処理を、**ActiveRecordのメソッドのみ**（SQLの生書きは避ける）を使って実装してください。また、それぞれの処理でN+1問題が絶対に発生しないよう、適切なメソッドを使って関連データを事前ロード（Eager Loading）してください。

**① 記事一覧と作成者・タグの同時取得**

- **要件**: すべての記事を取得し、それぞれの「記事タイトル」「作成者の名前」「紐づく全タグの名前」を一覧で表示したい。
- **注意点**: 記事ループ内で `article.user.name` や `article.tags` を呼んだ際に、都度SQLが発行されないようにすること。

**② 特定の記事に紐づくコメント一覧と投稿者情報の取得**

- **要件**: 特定の1本の記事（例: `id: 1`）に紐づくコメントをすべて取得し、それぞれの「コメント内容」と「コメントしたユーザーの名前」を表示したい。
- **注意点**: コメントのループ内で `comment.user.name` を呼ぶ際のN+1問題を回避すること。

**③ 【発展】「特定のタグ」を持ち、かつ「コメントが1件以上ある」記事の検索**

- **要件**: 例えば「Ruby」という名前のタグが付いている記事の中から、さらにコメントが1件以上書き込まれている記事だけを絞り込んで取得したい。
- **注意点**: 条件による絞り込み（`joins` や `left_outer_joins` などの適切な使い分け）と、データ表示時のN+1回避を両立させること。

## サーバー起動手順

### 1. gemをインストールする

```bash
bundle install
```

### 2. データベースを作成する

```bash
bin/rails db:create
```

### 3. Railsサーバーを起動する

```bash
bin/rails server
```
